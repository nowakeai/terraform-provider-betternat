# v0.2.3

## Generation-Safe AWS Gateway Replacement

This provider patch imports BetterNAT v0.2.3 and closes the replacement-state
ownership gap found during a real AWS gateway recovery.

## What Changed

- Unsafe AWS ownership and topology changes, including changes to
  `eip_allocation_ids`, are marked as replacements during `terraform plan`.
- Every physical create receives a read-only `generation_id`.
- Auto Scaling groups and launch templates use generation-scoped names and
  carry a `BetterNATGeneration` tag.
- Superseded or deposed generations cannot refresh from, roll back routes for,
  or clean up the current generation.
- Failed create retries receive a fresh generation and fresh physical pool
  names.
- Launch-template name-release retries use a bounded ten-minute deadline.

## Compatibility

- Existing v0.2.x configurations remain valid.
- Existing states remain on legacy names until their next physical
  replacement.
- Shared resources keep stable logical names, preserving external and retained
  EIP behavior.
- Supported runtime artifact versions remain `v0.2.0` and `v0.2.1`; provider
  package and runtime versions are independent.
